# Joplin Minimap

[Joplin](https://joplinapp.org/) のノートビューア用、ホバーで展開する目次ミニマップ。右端に見出しのティックバーを表示し、ホバーするとクリック可能なアウトラインに展開します。

[English](README.md) | [中文说明](README-CN.md)

## 機能

- **ティックバー・ミニマップ** — 各見出しをビューア右端に短い横線で表示。線の長さは見出しレベルを表します(H1 が最長)
- **デスクトップとモバイル** — デスクトップはホバー、タッチ端末はタップ。畳んだ状態では帯全体が一つのタップ対象になり、開くと行もボタンも指で押せる大きさに広がります。外側をタップするか見出しを選ぶと閉じます
- **ホバーで展開** — マウスを乗せると、レベルごとにインデントされた完全な目次オーバーレイに展開。長いタイトルは省略記号で切り詰め
- **階層ステッパー** — 展開パネル上部の `+` / `-` ボタンでアウトラインの深さを増減でき、入れ子の深い長いノートもワンクリックで最上位構造だけに畳めます
- **見出しの階層表示** — 上位の見出しほど大きく太く表示され、文書の構造が一目で分かります
- **クリックでジャンプ** — 項目をクリックすると該当見出しへスムーズスクロール
- **現在位置の表示** — 表示中のセクションを自動でハイライト
- **自動再構築** — ノートの切り替えや編集時に自動で再構築(`joplin-noteDidUpdate` を監視、MutationObserver でフォールバック)
- **RTL 対応** — ペルシア語・アラビア語・ヘブライ語など右から左に読む見出しは、展開パネルで右揃え・右からのインデントになります。見出しごとに方向を判定するため、混在したノートでも崩れません
- **テーマ対応** — ライト/ダークテーマに自動追従(`currentColor` から色を継承)
- **邪魔をしない** — 見出しが 2 個未満のノートでは非表示。印刷/エクスポート時も非表示。フォーカスやキーボード入力を奪いません

## インストール

### Joplin プラグインリポジトリから(公開後)

1. Joplin → **ツール → オプション → プラグイン**
2. **Joplin Minimap** を検索
3. インストールして Joplin を再起動

### ファイルから

1. [最新リリース](https://github.com/lim0513/joplin-minimap/releases/latest) から `plugin.jpl` をダウンロード
2. Joplin → **ツール → オプション → プラグイン**
3. 歯車アイコンから**ファイルからインストール**を選択
4. ダウンロードした `.jpl` ファイルを選択
5. Joplin を再起動

## 使い方

見出しが 2 個以上あるノートを**レンダリングされた Markdown ビューア**(閲覧モード、または分割エディタのプレビュー側)で開きます:

- 右端にティックバーの列が表示されます
- **ホバー**すると完全な目次に展開
- **クリック**で該当見出しへジャンプ

注意:ミニマップはレンダリングビューアのみに表示されます。Markdown エディタやリッチテキストエディタには表示されません。

## 仕組み

markdown-it コンテンツスクリプトがビューアに 2 つのアセットを注入します。`minimap-view.js` がレンダリング後の `h1`–`h6` 要素からミニマップを動的に構築し、`minimap.css` が折りたたみ/展開のスタイルを担当します。Markdown のレンダリング自体には手を加えません。

## 設定

**ツール → オプション → Joplin Minimap** で設定できます:

- **最少見出し数** — ノートの見出しがこの数未満の場合はミニマップを非表示(デフォルト 2)
- **展開パネルの幅 (px)** — ホバーで展開した目次の最大幅(デフォルト 240)
- **ミニマップの位置** — ミニマップをビューアのどちら側の端に表示するか、右または左(デフォルト右)
- **既定の階層の深さ** — ノートを開いたときに表示する見出しの深さ。`+`/`-` ボタンでいつでも変更できます(デフォルト 6、すべての階層)
- **端からの距離 (px)** — ミニマップとビューア端の間隔(デフォルト 6)
- **文字サイズ (%)** — 展開パネル内の文字を拡大縮小します。高解像度ディスプレイでは大きめに(デフォルト 100、「詳細設定」内)
- **高コントラスト表示** — 文字を明るく、パネル背景を濃くします。固定色を使わないためテーマには追従します(デフォルト オフ、「詳細設定」内)

設定の変更は次のレンダリング時に反映されます(ノートを切り替えるか編集してください)。

### スタイルのカスタマイズ

パネルの色とサイズはすべて CSS 変数を参照しているため、Joplin のプロファイルディレクトリにある `userstyle.css` から変更できます(このファイルはレンダリング後のノートビューア、つまりミニマップが表示される場所に適用されます)。`:root` に書けば `!important` は不要です:

```css
:root {
  --jp-mm-font:  15px;                      /* 基準の文字サイズ     */
  --jp-mm-color: #e8e8e8;                   /* 見出しの文字色       */
  --jp-mm-bg:    rgba(30, 30, 30, 0.92);    /* 展開パネルの背景     */
  --jp-mm-dim:   0.85;                      /* 非選択行の不透明度   */
  --jp-mm-dot:   #cd6155;                   /* 未完了ToDoのドット   */
  --jp-mm-width: 320px;                     /* 展開パネルの最大幅   */
}
```

Joplin が作成して開いてくれます:**ツール → オプション → 外観 → 詳細設定を表示 → レンダリングされた Markdown 用のカスタムスタイルシート**。ファイルが無ければ自動で作成されます。直接編集する場合は、プロファイルディレクトリの `userstyle.css`(Windows は `%USERPROFILE%\.config\joplin-desktop\`、その他は `~/.config/joplin-desktop/`)です。編集後は Joplin を再起動してください。

まずは**高コントラスト表示**をお試しください。色を指定しないので、テーマを変えても効果が失われません。


## 開発

依存関係ゼロ、`npm install` 不要:

```bash
npm run dist
```

`dist/`(Joplin の **Development plugins** 設定でプロジェクトルートを指定して読み込み可能)と `publish/`(`publish/plugin.jpl` を含む)が生成されます。
