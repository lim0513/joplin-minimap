# Joplin Minimap

[Joplin](https://joplinapp.org/) 阅读视图的悬停展开式大纲(ToC minimap)——右侧边缘的标题刻度条,悬停展开为可点击的目录。

[English](README.md) | [日本語](README-JA.md)

## 功能

- **刻度条 Minimap** — 每个标题在阅读视图右侧显示为一根小横线,长短代表标题层级(H1 最长)
- **桌面端与移动端** — 桌面悬停,触屏点按:收起时整条是一个点击目标,展开后行高和按钮放大到适合手指,点外面或选中标题即收起
- **悬停展开** — 鼠标移上去即展开为完整目录浮层,按层级缩进,超长标题省略号截断
- **层级步进** — 展开面板顶部的 `+` / `-` 按钮可调节大纲显示到第几级,长嵌套笔记一键收成顶层结构
- **钉住为侧栏** — 展开面板顶部的钉子按钮可把目录常驻为侧栏(类似 Obsidian 的大纲),并把正文让开、不会被遮住;阅读时当前标题始终保持在可见范围。也可在设置里开启
- **标题分级** — 顶层标题字号更大、字重更粗,文档结构一眼可辨
- **点击跳转** — 点击任意条目平滑滚动到对应标题
- **阅读位置** — 当前所在章节自动高亮
- **实时重建** — 切换笔记或编辑内容时自动重建(监听 `joplin-noteDidUpdate`,MutationObserver 兜底)
- **RTL 适配** — 波斯语、阿拉伯语、希伯来语等从右向左的标题，在展开面板中右对齐并从右侧缩进；方向按标题逐条判断，中英混排笔记也能正常显示
- **主题自适应** — 自动跟随明暗主题(颜色继承自 `currentColor`)
- **不打扰** — 少于 2 个标题的笔记不显示;打印/导出时不显示;不抢占焦点和键盘输入

## 安装

### 从 Joplin 插件市场(发布后)

1. Joplin → **工具 → 选项 → 插件**
2. 搜索 **Joplin Minimap**
3. 安装并重启 Joplin

### 从文件安装

1. 从 [最新 Release](https://github.com/lim0513/joplin-minimap/releases/latest) 下载 `plugin.jpl`
2. Joplin → **工具 → 选项 → 插件**
3. 点击齿轮图标,选择**从文件安装**
4. 选择下载的 `.jpl` 文件
5. 重启 Joplin

## 使用

在**渲染后的 Markdown 阅读视图**(阅读模式,或分栏编辑的预览侧)打开任意含 2 个以上标题的笔记:

- 右侧边缘出现一列刻度条
- **悬停**展开完整目录
- **点击**条目跳转到对应标题

注意:minimap 只在渲染视图中显示,纯 Markdown 编辑器和富文本编辑器中不显示。

## 实现原理

通过 markdown-it content script 向渲染视图注入两个资源:`minimap-view.js` 在每次渲染后从 `h1`–`h6` 元素动态构建 minimap,`minimap.css` 负责收起/展开样式。不改动 Markdown 渲染本身。

## 设置

在 **工具 → 选项 → Joplin Minimap** 中配置:

- **最少标题数** — 笔记标题少于此数时不显示 minimap(默认 2)
- **展开面板宽度 (px)** — 悬停展开目录的最大宽度(默认 240)
- **小地图位置** — minimap 停靠在阅读视图的哪一侧边缘,右侧或左侧(默认右侧)
- **默认层级深度** — 打开笔记时显示到第几级标题,`+`/`-` 按钮可随时调整(默认 6,全部层级)
- **常驻展开(钉住)** — 目录作为常驻侧栏显示,而不是悬停时才展开;面板里的钉子按钮切换的就是这一项(默认关闭)
- **边缘距离 (px)** — minimap 与阅读视图边缘的间距(默认 6)
- **文字大小 (%)** — 缩放展开面板里的文字,高分屏可调大(默认 100,位于「高级」)
- **高对比度面板** — 文字更亮、面板背景更实,不使用固定颜色,仍跟随主题(默认关闭,位于「高级」)

修改后在下次渲染时生效(切换笔记或编辑内容即可)。

### 自定义样式

面板用到的颜色和尺寸全部走 CSS 变量，可以在 Joplin 配置目录的 `userstyle.css` 里改（它作用于渲染后的笔记视图,也就是 minimap 所在的地方）。写在 `:root` 上即可,不需要 `!important`:

```css
:root {
  --jp-mm-font:  15px;                      /* 基准字号       */
  --jp-mm-color: #e8e8e8;                   /* 目录文字       */
  --jp-mm-bg:    rgba(30, 30, 30, 0.92);    /* 展开面板背景   */
  --jp-mm-dim:   0.85;                      /* 非当前行不透明度 */
  --jp-mm-dot:   #cd6155;                   /* 未完成待办圆点 */
  --jp-mm-width: 320px;                     /* 展开面板最大宽度 */
}
```

让 Joplin 帮你创建并打开:**工具 → 选项 → 外观 → 显示高级设置 → 渲染 Markdown 的自定义样式表**。文件不存在时会自动新建。想直接编辑的话,它就是配置目录里的 `userstyle.css`(Windows 上是 `%USERPROFILE%\.config\joplin-desktop\`,其他系统是 `~/.config/joplin-desktop/`)。改完重启 Joplin 生效。

建议先试**高对比度面板**——它不挑任何颜色就能解决大部分看不清的问题,换主题也不会失效。


## 开发

零依赖,无需 `npm install`:

```bash
npm run dist
```

生成 `dist/`(Joplin **Development plugins** 设置指向项目根目录即可加载)和 `publish/`(含 `publish/plugin.jpl`)。
